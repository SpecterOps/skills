# double

**Category:** Math

**Source:** https://sleep.dashnine.org/manual/double.html

---

## Synopsis

```sleep
$ double(n)
```

Convert the specified value to a double scalar

## Parameters

`n` - the value to apply this function to.

## Returns

A double scalar.

## Examples

**Example:**
```sleep
$value = double(4);
println($value);

```

**Output:**
```
4.0

```
