# sqrt

**Category:** Math

**Source:** https://sleep.dashnine.org/manual/sqrt.html

---

## Synopsis

```sleep
$ sqrt(n)
```

Calculate the rounded positive square root value of the argument.

## Parameters

`n` - the value (converted to a double) to apply this function to.

## Returns

A double scalar.

## Examples

**Example:**
```sleep
$result = sqrt(16);
println("sqrt(16) is $result");

```

**Output:**
```
sqrt(16) is 4.0

```
