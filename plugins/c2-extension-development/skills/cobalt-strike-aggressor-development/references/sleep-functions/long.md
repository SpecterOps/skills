# long

**Category:** Math

**Source:** https://sleep.dashnine.org/manual/long.html

---

## Synopsis

```sleep
$ long(n)
```

Convert the specified value to a long scalar

## Parameters

`n` - the value to apply this function to.

## Returns

A long scalar.

## Examples

**Example:**
```sleep
$value = long(3.56);
println($value);

```

**Output:**
```
3

```
