# lc

**Category:** Strings

**Source:** https://sleep.dashnine.org/manual/lc.html

---

## Synopsis

```sleep
$ lc("STRiNG")
```

Returns a lowercase version of the specified string

## Parameters

`"STRiNG" - the string to lowercase.` -

## Returns

A scalar string.

## Examples

**Example:**
```sleep
$string = lc("tHIS iS a tEST");
println($string);

```

**Output:**
```
this is a test

```
