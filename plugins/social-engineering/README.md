# Social Engineering

Target-specific social engineering workflows for source-research, voice matching, and phishing pretext development.

This plugin is the default home for:

- end-to-end phishing workflow orchestration
- pretext brainstorming from recent public events
- phishing email pretexts
- phishing email HTML generation
- GoPhish and Phishmonger email formatting
- vishing scripts
- credential-harvest landing-page copy
- target-specific lure refinement
- voice and sender-persona research
