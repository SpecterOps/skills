# Persuasion Principles

Use this reference when generating or refining any pretext.

Select one primary principle unless the task clearly benefits from a secondary one.

## Authority

Use when the message can plausibly come from leadership, IT, security, HR, payroll, benefits, legal, facilities, or an external vendor with recognized control over a process.

Common patterns:

- policy update
- security action required
- system migration
- mandatory review
- executive town hall

## Reciprocity

Use when the lure offers help, access, a correction, a convenience, or a perceived benefit in return for action.

Common patterns:

- support follow-up
- benefits clarification
- shared notes
- corrected document
- meeting recording

## Greed

Use when the lure promises gain, savings, rewards, or early access.

Common patterns:

- rebate
- allowance
- incentive
- discount
- bonus information

## Commitment and Consistency

Use when the target is framed as continuing, confirming, or completing something they already started or are expected to support.

Common patterns:

- follow-up review
- action item closure
- annual acknowledgment
- enrollment confirmation
- dry run participation

## Social Proof

Use when the lure implies peers, other teams, or the broader organization are already participating.

Common patterns:

- department rollout
- cross-team review
- employee-wide session
- common issue trends
- peer attendance

## Liking

Use when the sender can sound familiar, collaborative, or helpful without becoming casual or implausible.

Common patterns:

- quick favor
- collaborative review
- friendly reminder
- team coordination

## Scarcity

Use when the target must act before access, time, inventory, or opportunity runs out.

Common patterns:

- limited enrollment window
- last review slot
- expiring access
- deadline reminder

## Curiosity

Use when the subject can create a knowledge gap the target wants to close.

Common patterns:

- see what changed
- updated FAQ
- confidential draft
- preview materials

## Fear and Anxiety

Use when the lure warns of risk, disruption, scrutiny, missed action, or security consequences.

Common patterns:

- account issue
- missed requirement
- audit follow-up
- support escalation
- policy exception

## Trust

Use when the lure relies on normal business process, established branding, or expected operational coordination.

Common patterns:

- standard review
- employee notice
- help desk coordination
- vendor-hosted meeting

## Shame or Embarrassment

Use sparingly. Best when the message suggests the target may have missed, delayed, or mishandled something and can fix it quietly.

Common patterns:

- unresolved action item
- incomplete response
- missing registration
- follow-up needed

## Selection Rules

- Prefer the principle that best matches the public anchor and required action.
- Avoid combining too many principles.
- Keep the principle implicit; the message should feel operational, not theatrical.
- If a principle requires facts the public record does not support, pick another one.
