# Code Review and QA

Focused workflows for reviewing code changes, exercising web apps, and validating implementation quality before merge.

## Skills

- `code-review`
- `cpp-core-guidelines`
- `webapp-qa`

For projects using [agent-qa](https://github.com/vostride/agent-qa), `webapp-qa` includes an [optional regression reference](skills/webapp-qa/references/agent-qa.md). agent-qa combines natural-language testing with advanced memidex memory and self-improvement; the reference covers selected web tests, run verdicts, and incomplete evidence.

This optional path requires an initialized agent-qa project, Node.js 24+, and the configured browser and model provider for live runs. Runs can change application data and incur provider costs. The skill's existing QA delegation, smoke-test, and Lighthouse requirements still apply.
