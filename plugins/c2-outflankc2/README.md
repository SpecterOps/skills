# Outflank C2

Focused workflows for Outflank C2 operations, BOF scripts, and bot development.

## Skills

- `oc2-bof-script-development`
- `oc2-bot-development`
- `oc2-ops`

## Outflank C2 MCP setup

The `oc2-ops` skill requires the Outflank C2 MCP server. Enable the MCP service in your OC2 deployment and configure it directly in your MCP client as `oc2`, using the deployment's MCP endpoint and your user PAT for authentication. See the documentation supplied with your OC2 deployment for installation and client setup.
