# exp

**Category:** Math

**Source:** https://sleep.dashnine.org/manual/exp.html

---

## Synopsis

```sleep
$ exp(n)
```

Returns Euler's number raised to the power of n

## Parameters

`n` - the value (converted to a double) to apply this function to.

## Returns

A double scalar.

## Examples

**Example:**
```sleep
$var = exp(2);
println("Value of e**2 = $var");

```

**Output:**
```
Value of e**2 = 7.38905609893065

```
