# uc

**Category:** Strings

**Source:** https://sleep.dashnine.org/manual/uc.html

---

## Synopsis

```sleep
$ uc("string")
```

Returns a uppercase version of the specified string

## Parameters

`"string" - the string to uppercase.` -

## Returns

A scalar string.

## Examples

**Example:**
```sleep
$string = uc("this Is a tEsT");
println($string);

```

**Output:**
```
THIS IS A TEST

```
